Local · macOS · Open source

Record the meeting.
Keep the notes.

Meeting Agent is a fully local macOS note-taker. It captures your mic and the far end of the call, transcribes on-device with whisper.cpp, and writes a structured summary with the claude CLI from templates you control. Audio never leaves your Mac.

How it worksFrom sound to notes in five steps

Capture is one Core Audio aggregate device with one IOProc, so the mic and system audio share a single clock.

01
CaptureSwift Process Tap: mic + system output, mixed to 16 kHz mono PCM
02
ChunkPython splits the stream into 6 s WAVs and drives the live level meter
03
Live captionsOptional: whisper.cpp on each 12 s window while you record
04
TranscribeOn Stop, the full recording is merged and transcribed with timestamps
05
Summarizeclaude -p with your template. Two matching .md notes are saved

The stackSmall, boring, local

No pip packages, no virtual audio driver, no ffmpeg.

LayerComponentNotes
CaptureCore Audio Process Tap (Swift)macOS 14.4+. Taps system output and the mic through one aggregate device; no BlackHole, no output rerouting.
ServerPython 3.9+ stdlibhttp.server, recorder, serial job worker, JSON API. Binds to 127.0.0.1.
UIVanilla JS single pageRecording list with generated titles, level meter, waveform player, live and final transcript, summary, settings.
Transcriptionwhisper.cpplarge-v3-turbo-q5_0: multilingual (English, Cantonese, Mandarin), ~570 MB.
Summaryclaude CLITemplate + meeting context + timestamped transcript. Only text is sent.
OutputMarkdown2026-10-11 15.00 - Title - Summary.md and … - Transcript.md, in a folder you choose.

Build itThree commands

Needs macOS 14.4+, Xcode Command Line Tools, and the claude CLI. Homebrew is optional.

# clone, then:
git clone https://github.com/dicksonyue/meeting-agent && cd meeting-agent
./setup.sh      # builds the tap, gets whisper-cli, downloads the model
./verify.sh     # end-to-end self-check (deps, build, pipeline, API, live capture)
./start.sh      # http://127.0.0.1:8765/
Permissions: approve Microphone and Audio Recording on first record. macOS ties them to the app that launched the server, so run ./start.sh from your own Terminal. If the level meter says "No signal", that is the first thing to check.
Swift version: if the build says the SDK is not supported by the compiler, install the matching Command Line Tools or Xcode (swiftc --version).

TemplatesSummaries shaped to the meeting

A template is a .md file in the templates folder. New files appear without a restart. Pick one before recording, or re-summarize any recording with another.

Meeting Summary

Date and speakers, discussion summary, verdict per topic, next actions, topics in detail with original quotes and conclusions, suggestions.

Interview

Background, Q&A with quotes, evidence-backed strengths and gaps, skills table, follow-ups.

Project Status Review

Green / Amber / Red, progress, milestones, risks and blockers, decisions needed, actions.

Panel

Panelists, discussion by question, agreement and disagreement, notable quotes, audience Q&A.

---
name: Daily Standup
description: Yesterday / today / blockers per person
---
Summarize this as a daily standup: for each person, what they did, what they will do, and blockers.

ConfigSettings and environment

Notes folder, templates folder and default template are set in the app (⚙ Settings). Environment variables override them.

VariableDefaultMeaning
MT_NOTES_DIR./notesWhere Summary and Transcript notes are written.
MT_TEMPLATES_DIR./templatesFolder of summary templates.
MT_PORT8765Server port.
MT_SAVE_DIR./transcriptsRaw sessions: chunks, audio, transcript JSON, summary history.
MT_MIC_NAMEsystem defaultSubstring of the input device to use as the mic.
MT_MODELmodels/ggml-large-v3-turbo-q5_0.binAny whisper.cpp ggml-*.bin model.
MT_CLAUDE_BINautoPath to the claude CLI.

See STACK.md for the full reference including the HTTP API and launchd autostart. Whisper has no speaker diarization, so speaker counts in summaries are estimates. Recording others may require their consent where you live.
